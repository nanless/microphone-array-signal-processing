# 工业接口与空间算法运行记录

## 范围与验收方法

本记录接续 `ROUND3_REVIEW.md` 和 `SOURCE_RESEARCH_REVIEW.md`，不追溯修改前两批的运行状态。
当前任务是实际运行 libsoxr、libebur128、libsndfile 接口实验，复现 SBL 与 SMP-PHAT 的小规模数值行为，
同步解释和可重跑程序，再提交此前累积修改。实验不是论文全量评测或真实设备验收。

三路先完成只读检查，再按文件互斥写入。工程组负责工业 C 程序、构建脚本、测试及研究 03；
空间组负责 SBL 程序、测试及研究 01；增强组负责 SMP-PHAT 程序和测试。
主审负责共享入口、研究 04、正文引用、独立复核、生成物及版本提交。

构建仅写入忽略的临时目录，不改上游工作树、不安装全局依赖。各报告分别绑定源码提交、实验程序摘要、
环境、输入和判据。上游代码不复制进本书；获取工具的 `execution: not_run` 仍表示它只获取源码。

## 已执行的数值复核

- 工业三库由工程组实际构建后，主审又在新临时目录从相同源码完整重编译一次。两份报告的
  `measurements` 逐项相等；源码前后均为 `source_verified`。编译日志、二进制和临时七帧 WAV 不进入提交。
- soxr 三种供给均得到 16000 帧，两种分块与整段最大差 0；排空补出 529、341、378 帧。
  清状态反例丢失 434 帧；脉冲时间和稳态正弦另用解析值检查。
- 响度半幅差 −6.020599913279625 LU，分块差 0；静音原返回负无穷，JSON 使用 `null` 和原因。
  PCM 短读返回 3/3/1/0 帧、6/6/2/0 标量项，归一化误差 0，标准库独立读回 14 个码字通过。
- SBL 五组实际调用通过入口核查。另一审查者从字面 ±j 列、Toeplitz 矩阵和标量几何级数独立复算总体谱，
  最大差 7.11e−15；逐项扫描迭代误差，确认 309、168、259 次满足阈值，两组 1000 次未满足。
  主审重跑 9 项 SBL 测试，包含实际作者代码调用和一次迭代上限反例。
- 在线 WPE 补来源声明后，抽头、状态、许可及两组独立分数手算共 6 项测试通过；实际对照误差仍为 2.3915e−15。
- SMP 数学独立审查：规则菱形的六对依次为 01/02/03/12/13/23，分组应为 `[0,1,2,2,3,0]`，
  极性 `[+,+,+,+,+,−]`；第四麦沿 y 移动 0.5 mm 后，原相等边长差为 0.000354923732 m，大于合并容差，
  应退化为六组。未归一化逆变换的独立探针包括 DC=3 得全 3、bin1=j 在四分之一周期得 −2，
  以及有效 bin0～31 全 1、原 Nyquist 置 0 时零滞后值为 63。
- 原版 SMP 的负浮点到无符号转换由主审另写六行核心的最小 C 程序检查：Apple clang 21、`-O2` 下
  输入 −6 转为 0；加入 `-fsanitize=float-cast-overflow -fno-sanitize-recover=float-cast-overflow` 后
  退出 134 并报告该值超出 unsigned int 表示范围。探针不复制上游实现，临时程序不进入提交。
  依据为 [Clang 官方手册对应选项](https://clang.llvm.org/docs/UsersManual.html)；不依赖编译器的偶然回绕行为。

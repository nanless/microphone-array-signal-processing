# 算法实现、工业部署与源码研究手册

本手册接在教程的数学推导之后，回答从式子走到真实实现时出现的问题：哪个数组对应观测，状态怎样跨帧保留，
控制信号从哪里取得，代码在哪个文件，怎样设计可以判断对错的实验。

材料依据原论文、维护者文档和官方仓库整理；各条目的核实日期以专题记录为准。版本清单见
[SOURCES.lock.json](../SOURCES.lock.json)，逐算法覆盖状态见 [COVERAGE.md](../COVERAGE.md)。
同名算法在不同项目中可能采用不同归一化、频谱轴序和输出参考通道，不能直接比较两个函数的数组而不检查约定。

本手册包括本页入口和以下 5 篇专题，共 6 个网页；与 16 个教程页合计为 22 页。

锁表登记 109 个 Git 上游项目，其中 92 个已有本地工作区。截至 2026-10-04，按完整稀疏选集政策离线核验69项通过，22个已取得的工作区仍使用旧排除规则，报告为选集不匹配并保留原样；AEC Challenge 的真实录音文件有本地变动，仍保留失败。另17项只保留来源索引。选集不匹配不等于源码未取得，也不代表算法运行失败。`kaldialign`作为MeetEval编译依赖仅已取得源码，未构建或执行。TAC作者的四文件选集已在独立忽略目录取得；其README声明的非商业许可、静态结构审计与未运行原网络的边界见[附录B源码合同](04_source_reproduction.md#tac-contracts)。

空间篇从双耳线索、SAF 的 HRIR/HRTF 和 libmysofa 数据接口讲起，再讨论 SBL、RobustSBL、在线子带 GSC、SMP-PHAT 与多帧关联；增强篇讨论在线 WPE 接口对照、DNN 自适应控制和长序列分离；工程篇讨论重采样、响度、STOI/ESTOI、ViSQOL、文件帧读写、块浮点及STK分数延迟状态。增强篇另核查TF-Locoformer固定源码的时频结构、形状和配置边界。

## 从一个问题开始阅读

- 定位峰方向相反：从时延正号、阵列坐标、FFT 相位和导向矢量的共轭关系检查，再讨论算法分辨率。
- 离线运行良好而设备失效：先检查音频时钟、参考取点、块长、历史状态和输入增益；这些条件会同时影响多个模块。
- 分离得分高而识别变差：核对分离输出的排列、通道参考、增益、时间对齐和评分区域，再检查语音损伤。
- 线性求解返回有限数组，却不满足约束或与手算不符：先读[附录 A 求解合同](04_source_reproduction.md#appendix-solver-contracts)，分开检查数据类型、数值秩、残差与物理目标。
- 想更换为论文中的新方法：先对齐论文的输入条件、训练信息、因果性与输出目标，再决定是否替换现有模块。
- 想复现附录B中的神经研究方向：从[八类任务与版本边界](04_source_reproduction.md#appendix-b-reproduction)选择一个输出目标，再核对源码、权重、数据和计时范围；TAC的静态结构证据不代替原网络运行。
- 想先复算一个答案、听辨一次时延或削波：从[练习与音频实验](05_exercises_and_audio.md)选择稳定题号或音频组，并结合图 34 核对波形与参数。合成样例不是自然语音，也不代替正式听测。

## 阅读源码的共同顺序

1. 读入口函数和配置，记录输入/输出形状、单位、采样率、参考通道与状态寿命。
2. 找状态初始化、正常更新、缺测/静音和重置四条路径。
3. 把计算对应到正文目标函数或递推式；优化器、加载、功率下限和投影属于实现的一部分。
4. 读维护者测试，区分形状测试、数值测试、音频质量测试和硬件测试。
5. 用本书的小规模输入或独立解析例做一次对照。运行成功和输出数值可信是两个不同结论。

| 源码核验 | 固定版本、本地文件和所选源码范围符合清单 | [Git 源码状态](../SOURCE_STATUS.json)、[归档源码状态](../ARCHIVE_SOURCE_STATUS.json) |

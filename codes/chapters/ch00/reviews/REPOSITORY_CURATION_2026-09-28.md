# 仓库整理审查与验收记录（2026-09-28）

## 范围与方法

本轮目标是核对按章迁移后的仓库结构、活跃出版说明、代码与资产定位、生成链和发布检查。审查先由内容导航、代码与来源、构建与产物三路独立只读完成，主审合并重复问题后按互斥文件修改。历史 `*_REVIEW_*.md` 保留当时路径和验证结论；本轮不借整理名义重写旧实验结果，也不覆盖被 Git 忽略的上游下载工作区。

修改源文件范围：`AGENTS.md`、双语 README、附录 B、`codes/chapters/ch00/` 的覆盖与来源索引、`scripts/README.md`、站点/PDF 构建说明与发布检查、相关测试。生成物由绘图、建站及合订脚本统一重建。验收包括本地链接与入口扫描、来源状态重生、音频摘要、49 张图、20 个网页、PDF 书签与分页、全仓测试和质量门禁。外部论文和软件版本本轮没有新增断言，不以搜索摘要替代原文。

# 第 3 章代码

`chapter03_experiments.py` 复算 E03-08～14 的阵列几何、模糊与校准例子；`coarray_covariance_exercise.py` 独立复算 E03-07 的虚拟滞后统计。两者使用数学输入和明确的阵列约定。

在仓库根目录运行：`.venv/bin/python -m codes.chapters.ch03.chapter03_experiments` 和 `.venv/bin/python -m codes.chapters.ch03.coarray_covariance_exercise`。旧的 `codes.examples` 对应模块与命令仍可使用。

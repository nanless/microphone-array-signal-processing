# 第 5 章：波束形成

这里保存第 5 章练习的实际实现。`chapter05_experiments.py` 汇总 E05 练习，`beamformer_common_input_demo.py` 在同一阵列和噪声条件下比较波束权重。通用算法仍由 `codes/chapters/` 提供。

从仓库根目录运行：

```bash
.venv/bin/python -m codes.chapters.ch05.chapter05_experiments
.venv/bin/python -m codes.chapters.ch05.beamformer_common_input_demo
```

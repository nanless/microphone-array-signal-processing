# 四类 AEC 方法的章节级审查与实施记录

范围：第 6 章的子带 AEC、IPNLMS、RLS、Kalman/FDKF/PBFDKF，以及直接对应的教学代码、练习、插图和合成音频。审查从 `AGENTS.md` 的章节级流程出发；三路独立只读审查完成后，才按互斥文件分工修改。来源核实日期：2026-09-23。

## 改动目标与验收方法

1. 保留现有已独立复算的 PBFDAF、RLS、矩阵 Kalman 锚点，给子带和 IPNLMS 增加可复核的变量、步骤、反例与连续更新代码。
2. 将四种方法在目录中可定位，题干、答案和代码使用稳定练习 ID；明确短实数教学实现与完整频域/工业系统的差距。
3. 增加由脚本生成的 AEC 图和同源、共增益的数学合成音频；把“示意、仿真、真实录音”及先验线性残差区分清楚。
4. 同步 `codes/COVERAGE.md`、研究手册、发布数量基线、网站和 PDF；独立复算数例，运行专项与全量测试，抽查最终图及 PDF。

## 原始来源与解释边界

- Gilloire 与 Vetterli，*IEEE Transactions on Signal Processing* 40(8)，1992，DOI [10.1109/78.149989](https://doi.org/10.1109/78.149989)：临界抽样子带模型需要核对交叉带滤波。
- Benesty 与 Gay，ICASSP 2002，[作者单位出版记录](https://cris.technion.ac.il/en/publications/an-improved-pnlms-algorithm/)；具体混合参数化另核 [EUSIPCO 2004 表 1](https://www.eurasip.org/Proceedings/Eusipco/Eusipco2004/defevent/papers/cr1026.pdf)。
- Lee 与 Gan，*IEEE Signal Processing Letters* 2004，DOI [10.1109/LSP.2004.833445](https://doi.org/10.1109/LSP.2004.833445)：NSAF 用子带误差更新全带滤波器，不能与每带独立滤波等同。
- Enzner 与 Vary，*Signal Processing* 86(6)，2006，DOI [10.1016/j.sigpro.2005.09.013](https://doi.org/10.1016/j.sigpro.2005.09.013)：FDKF 的状态空间方法，不由标量卡尔曼一步算术直接复现。
- Zhu 等，Interspeech 2021，[论文 §2～3](https://www.isca-archive.org/interspeech_2021/zhu21d_interspeech.pdf)：分区频域观测约束与 VD/SD 协方差近似，实验条件不可外推到本书新合成例。

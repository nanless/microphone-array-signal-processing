## 从一个问题开始阅读

- 定位峰方向相反：从时延正号、阵列坐标、FFT 相位和导向矢量的共轭关系检查，再讨论算法分辨率。
- 离线运行良好而设备失效：先检查音频时钟、参考取点、块长、历史状态和输入增益；这些条件会同时影响多个模块。
- 分离得分高而识别变差：核对分离输出的排列、通道参考、增益、时间对齐和评分区域，再检查语音损伤。
- 想更换为论文中的新方法：先对齐论文的输入条件、训练信息、因果性与输出目标，再决定是否替换现有模块。
- 想先复算一个答案、听辨一次时延或削波：从[练习与音频实验](05_exercises_and_audio.md)选择稳定题号或音频组，并结合图 34 核对波形与参数。合成样例不是自然语音，也不代替正式听测。

## 阅读源码的共同顺序

1. 读入口函数和配置，记录输入/输出形状、单位、采样率、参考通道与状态寿命。
2. 找状态初始化、正常更新、缺测/静音和重置四条路径。
3. 把计算对应到正文目标函数或递推式；优化器、加载、功率下限和投影属于实现的一部分。
4. 读维护者测试，区分形状测试、数值测试、音频质量测试和硬件测试。
5. 用本书的小规模输入或独立解析例做一次对照。运行成功和输出数值可信是两个不同结论。
